# 提词器Prompt 发布准备清单

## 功能验收

- 新建脚本、编辑脚本、搜索脚本、星标置顶都能在首页、脚本列表、提词内脚本列表即时同步。
- 全屏提词支持倒计时、播放/暂停、从头开始、手动拖动到任意文字位置、黑底白字/白底黑字、镜像。
- 拍摄提词使用 App 内相机预览，支持前后摄像头、焦段、画面比例、录制保存到系统相册。
- 拍摄提词里的相机按钮固定显示，点击屏幕只影响提词功能栏，不影响相机底座。
- 设置页的字号、速度、倒计时、继续倒计时、默认摄像头、全局黑白显示偏好会即时保存在本机。

## 设备验证

- iPhone 竖屏：完整走通新建脚本 -> 编辑 -> 星标 -> 搜索 -> 全屏提词 -> 拍摄提词 -> 录制保存 -> 设置切换 -> 重启 App。
- iPad 竖屏：确认首页、脚本列表、新建脚本页内容区域不拉满，提词文字居中。
- iPad 横屏：确认全屏提词和拍摄提词不穿模，底部按钮不遮挡相机操作区。
- 真机：验证相机、麦克风、相册写入权限，以及拒绝权限后的去设置提示。

## App Store 信息

- App 名称：提词器Prompt。
- Bundle ID：`com.sheng.teleprompterprompt`。
- 隐私说明：不登录、不云同步、不上传脚本内容、不上传录制视频。
- 权限说明：相机用于 App 内拍摄提词预览与录制，麦克风用于录制口播声音，相册写入用于保存录制视频。
- 截图：准备 iPhone 与 iPad 各一组，覆盖首页、脚本列表、全屏提词、拍摄提词、设置。
