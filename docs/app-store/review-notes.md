# App Review Notes

App name: 提词器Prompt

This app is a local teleprompter for short-video talking-head creators.

Camera and microphone are used only in `拍摄提词`, where the user records talking-head video with teleprompter text overlaid on the in-app camera preview.

Photos add access is used only after recording, so the completed video can be saved to the user's system Photos library.

Scripts are stored locally on the user's device. The MVP has no account login, no cloud sync, no server upload, and no in-app video library.
