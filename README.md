# 提词器Prompt

提词器Prompt 是一款面向短视频口播创作者的 iOS / iPadOS 提词器 App。它解决的是拍摄口播时脚本难管理、远近距离提词不方便、临时重录时难以快速回到指定段落的问题。

当前版本坚持本地优先：不登录、不云同步，脚本内容保存在设备本机。

## 主要功能

- 脚本管理：新建、编辑、搜索脚本，支持星标置顶。
- 首页快捷入口：拍摄提词、全屏提词、设置。
- 全屏提词：大字提词、自动滚动、倒计时、播放/暂停、从头开始、字号和速度调整、黑底白字/白底黑字、镜像显示。
- 拍摄提词：App 内相机预览，提词框叠加在画面中，可调整位置、大小和透明度。
- 拍摄控制：支持前后摄像头切换、焦段切换、画面比例切换、录制视频并保存到系统相册。
- 设置页：默认字号、速度、倒计时、继续倒计时、默认摄像头、显示主题和自动隐藏控制栏。
- 本地隐私：脚本和设置使用 SwiftData 本地存储，录制视频仅在用户保存时写入系统相册。

## 安装方法

1. 安装 Xcode。
2. 克隆或下载本项目。
3. 使用 Xcode 打开：

```bash
open TeleprompterApp.xcodeproj
```

4. 选择 `TeleprompterApp` scheme。
5. 选择 iPhone 或 iPad 模拟器运行。

真机调试和 App Store 发布需要在 Xcode 中配置 Apple Developer Team。

## 使用方法

1. 打开 App，进入首页。
2. 点击「新建脚本」，输入标题和正文并保存。
3. 从首页脚本列表点击脚本，默认进入全屏提词。
4. 在提词页面底部可切换「全屏提词」和「拍摄提词」。
5. 点击「拍摄提词」可进入 App 内相机模式，开始录制后视频可保存到系统相册。
6. 在「设置」中调整默认字号、速度、倒计时、显示主题和默认摄像头。

## 输入输出示例

输入脚本：

```text
标题：黄金手镯口播脚本

正文：
这几件都是足金。
但放在同一盏灯下面，反光完全不一样。
差别，就藏在表面工艺里。
```

App 输出：

```text
脚本列表中新增「黄金手镯口播脚本」。
点击脚本后进入提词页面。
全屏提词显示大字滚动内容。
拍摄提词在相机预览中间显示可移动提词框。
录制完成后，视频保存到系统相册。
```

## 权限说明

- 相机：用于拍摄提词中的相机预览和视频录制。
- 麦克风：用于录制口播声音。
- 相册写入：用于将录制完成的视频保存到系统相册。

App 不收集用户数据，不上传脚本内容，不上传录制视频。
